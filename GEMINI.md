## 2. Database Connection & Zero-Secret Cloud Architecture

### A. Zero-Secret Mobile & Native Architecture (`src/turso.js` & `TpsGeofenceReceiver.kt`)
- **No Secrets in APK**: All direct Turso connection URLs and authentication tokens are removed from JavaScript code and native Kotlin bytecode.
- **Secure Vercel Gateway Proxy**: Mobile queries route via HTTPS `POST https://tapowan-school.vercel.app/api/db/query` and `POST /api/db/batch` (or `https://tapowan-app.vercel.app/api/db/query`).
- **Read-Only Directory Access & Sanitization Filter (`server.js`)**: All `SELECT` read queries (e.g. `SELECT COUNT(*) FROM students`, student roster by class, fees, dues, and attendance queries) are permitted through `/api/db/query` without requiring session cookies or bearer tokens. Mutating statements (`INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`) remain strictly authenticated and protected. Returned rows automatically pass through `sanitizeResultRows()` to strip sensitive passwords/auth hashes before reaching clients.
- **Native Android Proxy Client (`executeProxyQuery`)**: Native Kotlin services (`TpsGeofenceReceiver.kt`) send parameterized SQL payloads `{"sql": sql, "args": args}` to the zero-secret proxy without embedding master JWT credentials in APK bytecode.
- **Administrative Safety Filter**: Dangerous DDL/admin operations (`DROP`, `ALTER`, `ATTACH`, `DETACH`) are blocked server-side.

## 3. Key Feature Architectures

### A. Strict Faculty & Student Authentication Security (`src/LoginScreen.js`)
1. **Teacher / Faculty Password Enforcement**:
   - `userRole === 'teacher'` strictly validates against the `users` table (`username = ? AND password = ?`).
   - Supports login with registered mobile number, Staff/Employee ID (`EMP-12` or `12`), or Full Name.
   - Enriches session data with department, qualification, and staff directory records from `teachers` table.
   - Informative, secure error handling: displays "Incorrect Password" with direct link to Sign Up / Reset, "Password Not Set" for unactivated directory members, or "Faculty Account Not Found".
2. **Student Authentication**:
   - Matches phone number or admission number with `students.appPassword`.
   - Distinguishes "Incorrect Password" vs "Account Not Found".
3. **Repository Credential Protection**:
   - `firebase-admin-key.json`, `*admin-key*.json`, and `*service-account*.json` are strictly untracked from Git and excluded via `.gitignore`.

### B. Hardware 50m Geofence Auto-Attendance & Departure Engine (`src/utils/AutoAttendanceEngine.js` & `TpsGeofenceReceiver.kt`)
1. **Perimeter & Physical Coordinates**:
   - **School Coordinates**: `23.8209682° N, 85.5119629° E` (Prem Nagar Campus).
   - **Radius**: Strictly **50.0 meters** (`SCHOOL_RADIUS_METERS = 50.0f` in Kotlin, `radiusMeters: 50.0` in JS).
   - **Diameter**: 100 meters (~1 standard football field length).
   - **Total Ground Area**: $\approx 7,854\text{ m}^2$ ($1.94\text{ acres}$).
   - **Coverage**: Encloses the main school building, classrooms, courtyard, and main gate entrance, strictly excluding surrounding residential quarters (`M.Q- BLOCK NO-02`) and bypass shops to prevent false arrival triggers.
2. **Attendance Timing & One-Time Arrival Lock**:
   - **One-Time Arrival**: Attendance is marked only once during morning school hours (`06:00 AM - 01:00 PM`). Once marked, subsequent entries/exits during the day cannot overwrite or reset the initial arrival timestamp.
   - **Timetable Working Hours**: Dynamic cutoff (default `07:00 AM - 02:40 PM` from `settings` / `timetable`).
   - **Status Auto-Calculation**: Arrival before or within 15 minutes of cutoff (`07:15 AM`) marks `Present`; arrivals after mark `Late`.
   - **2-Hour Departure Guardrail**: Any departure occurring at least 2 hours after school start (`arrivalTotalMinutes + 120`, e.g. 09:00 AM onwards) automatically updates `departureTime` without touching arrival time.
3. **Zero-Secret Native Sync**:
   - Replaced direct Turso pipeline calls with `executeProxyQuery(sql, args)` calling `https://tapowan-app.vercel.app/api/db/query` with automatic failover to `https://tapowan-school.vercel.app/api/db/query`.
4. **Offline Timestamp Persistence**:
   - If mobile data is OFF upon arrival, Android `SharedPreferences` (`tps_teacher_session`) logs timestamps and marks `pending_arrival_sync = true`. Once network restores, `AutoAttendanceEngine.js` automatically reconciles with Turso Cloud.

### H. Automated WebRTC Fee Reminder & Interactive IVR Calling Engine (`server/call-automation.js`, `public/call_automation_module.js`, `VoiceCallContext.js`, `VoiceCallModal.js`)
1. **Zero-VoIP-Cost High-Fidelity WebRTC Calling Pipeline**:
   - Web Portal acts as an automated interactive voice caller generating native WebRTC VoIP calls to students/parents with zero per-minute telecom carrier costs.
   - Dual-channel Web Audio mixer: combines Neural Google TTS synthesized voice chunks (streamed into `createMediaStreamDestination()`) with live operator microphone toggle for manual talk-over/support.
   - Multilingual voice prompt generator: supports Hindi, English, and Hinglish with dynamic student name, outstanding due amount, and interactive keypress instructions.
2. **Real-Time Interactive In-Call DTMF / Keypress ("Press 1 for Payment Link or QR")**:
   - Recipient device receives high-priority VoIP call notification identifying `📢 Automated Fee Reminder Call` and outstanding due balance.
   - Connected call screen displays a prominent interactive `[ 1 ] Press 1 for Payment Link & QR` action card and numeric keypad (0–9, *, #) with haptic feedback.
